# Strumly 🎸

**Learn guitar with a practice partner that listens.** Strumly is a free, private, offline-capable
web app (PWA). It hears you play through your microphone, waits for you in **Wait Mode**, scores
your timing in **Play-along**, and coaches you through a guided beginner curriculum and a library
of public-domain songs.

> This repository was formerly a placeholder named `python-hangman`. It now hosts Strumly.

_(This README is expanded in Sprint 5. See [`docs/README.md`](docs/README.md) for the full project playbook.)_

## Quick start

```bash
npm install
npm run dev        # open http://localhost:5173 (the mic needs localhost or HTTPS)
npm run check      # typecheck, lint, tests, build
```
