# User journeys

**Owner:** Business Analyst with UX Designer

## J1: First session (Sam, P1). Target: a first win in under 2 minutes

1. Opens Strumly → Welcome → picks "brand new", acoustic, right-handed.
2. Mic explainer → allows → the level meter jumps when Sam plucks a string → "We can hear you!"
3. Offered the tuner → tunes the low E → continues to Home.
4. "Continue: Lesson 1 · Open high e" → tip cards (how to hold the pick, string 1 = thinnest).
5. Wait Mode: each gem waits. Sam plucks, the gem turns ✓ and the highway moves on.
6. Results: ★★★, "Perfect start!", +XP, streak day 1 → "Next lesson".

## J2: Chord practice (Priya, P2)

1. Home → Unit 3 → "Em ↔ Am changes" → switches to Play-along at 70%.
2. Misses changes → Results: 2★, coach tip "You were late on changes into Am. Start moving on beat 4."
3. Taps "Retry" with A–B loop on bars 2–3 → 3★ → coach suggests 80%.

## J3: No guitar handy (Leo, P3)

1. Mic denied → "Practice without a guitar" → the on-screen fretboard appears under the highway.
2. Taps frets to play the lesson. The full scoring loop works (useful for demos).

## J4: Check a chord (Jordan, P4)

1. Chords tab → D (mirrored diagram because left-handed mode is on).
2. "Check my chord" → strums → "Almost! F♯ is quiet. Check your ring finger on the high e string." The feedback shows an icon and text, not just colour.

## J5: Song play (Sam)

1. Songs → "Ode to Joy" (difficulty 1) → Melody → Wait Mode → then Play-along at 80%.
